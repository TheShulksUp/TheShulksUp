## Featured project

### OfflineYT — your own offline YouTube library

Mirror the channels you *actually watch* to your disk, driven by your real Google Takeout watch history. Continuous per-channel budgets, auto-rotation, ad auto-purge, and a 6am daemon — so a growing personal library never needs babysitting.

> [github.com/TheShulksUp/offlineyt](https://github.com/TheShulksUp/offlineyt) — one-file Python tool (`yosync`), no services, your data stays yours.
